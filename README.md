# OLA Ride Booking Data Analytics Dashboard

## 📊 Project Overview
This project is an interactive Power BI dashboard created to analyze OLA ride booking data.
The dashboard focuses on booking performance, revenue, cancellations, ride trends, payment methods, and customer/driver ratings.
The project demonstrates how Power BI can be used to transform ride-booking data into meaningful business insights.

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization
- Data Analytics

## 📁 Dashboard Pages
### 1. Overall Analysis
The Overall dashboard provides a high-level view of booking performance.
Key metrics include:
- Total Bookings
- Total Booking Value
- Successful Bookings
- Cancelled Bookings
- Booking Status Breakdown
- Ride Volume Over Time

### 2. Revenue Analysis
The Revenue dashboard analyzes booking value by payment method.
It includes:
- Revenue by Payment Method
- Cash
- UPI
- Credit Card
- Debit Card
- Top 5 Customers
- Ride-distance trends over time

### 3. Cancellation Analysis
The Cancellation dashboard focuses on cancelled rides.
It analyzes:
- Customer cancellation reasons
- Driver cancellation reasons
- Cancelled Bookings
- Cancellation Rate
- Major cancellation categories

### 4. Ratings Analysis
The Ratings dashboard compares:
- Driver Ratings
- Customer Ratings
- Vehicle Types

Vehicle categories include:
- Prime Sedan
- Prime SUV
- Prime Plus
- Mini
- Auto
- Bike
- E-Bike

## 📌 Key Dashboard Metrics
The dashboard shows approximately:
- **89.9K** total bookings
- **55.9K** successful bookings
- **25.2K** cancelled bookings
- **28.05%** cancellation rate
- **30.58M** total booking value
These values are based on the dashboard screenshots and selected date range.

## 💡 Business Insights
Some observations from the dashboard include:
1. Successful bookings represent the largest booking-status category.
2. Driver and customer cancellations form a significant portion of total bookings.
3. Cash and UPI contribute the majority of the displayed booking revenue.
4. Ride volume remains relatively consistent throughout the displayed period.
5. Driver and customer ratings remain close to the 4.0 level across vehicle categories.
6. Cancellation reasons can help identify areas where the ride-booking experience could be improved.

## 🎯 Project Objective
The main objective is to use data visualization and business intelligence techniques to understand:
- Booking performance
- Revenue contribution
- Cancellation behavior
- Customer and driver satisfaction
- Ride-volume trends
- Payment-method usage

1. Download the `.pbix` Power BI file.

3. Use the date filters to explore the dashboard.
4. Select different dashboard sections to analyze bookings, revenue, cancellations, and ratings.
